# NIP-51 ミュート 実装計画

**Goal:** NIP-51 の公開・非公開ミュートを読み書きし、カラム、スレッド、設定画面へ一貫して適用する。

**Architecture:** `MuteList` をアカウント単位の interface とし、kind:10000、暗号方式、Writer、EventStore を内側へ隠す。Store は受信イベントを保持し、カラム直下では仮想リストへ渡す前、入れ子では `EventView` の共通入口で表示を抑制する。

**Tech Stack:** SolidJS / TypeScript / Ark UI / Vitest / Playwright / pnpm

**Spec:** [`docs/superpowers/specs/2026-08-27-nip51-mute-design.md`](../specs/2026-08-27-nip51-mute-design.md)

## 全体制約

- v1 のプリミティブは Ark UI を使い、Kobalte を増やさない
- 復号済み非公開項目はセッションメモリだけに置く
- NIP-44 が使えないとき、非公開指定を公開保存へ縮退しない
- 公開・非公開の未知タグを保存時に落とさない
- SubscriptionManager と EventStore ではミュート対象を捨てない
- テストは捕まえる変異を記し、実際に赤くなることを確認する
- `src/core/nostr/build/**` と `src/core/write/**` の変更後は mutation test を通す
