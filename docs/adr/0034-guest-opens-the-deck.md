# ログインしていなくても、同じデッキを開く

ログインしていない人にも、ログインした人と同じデッキの画面を開く。先頭に「紹介とログイン」のカラム（`kind: "welcome"`）を置き、そこから始め方を選んでもらう。ログインの要る操作（リアクション・投稿・フォローなど）は押せる見た目のまま残し、押したらそのカラムへ送って「ログインすると〜ができます」と知らせる。自分に紐づくカラム（ホーム・通知・ブックマーク・リスト）は、中身の代わりにログインを勧める。

ログインしていない人のデッキは、署名できないのでアカウントへは保存せず、この端末の `streets.v1.deck.guest` にだけ置く。ログインしたらその人のデッキを開き、ログイン前のデッキは引き継がない。

## なぜ

Nostr は読むだけならログインが要らない。専用の入口の画面にすると、マルチカラムの操作（カラムを並べる・重ねて開く・URL から一時カラムを開く）を、ログインするまで試せない。「すべてはカラム」という前提に戻し、紹介とログインもカラムにすれば、同じ画面のまま触ってもらえる。v0 も同じ形だった。

## 捨てた案

- **ログイン前専用の入口の画面**：作りは小さいが、デッキの操作をそこで作り直すことになり、URL の一時カラム（[ADR-0032](./0032-url-opens-a-temporary-column.md)）も別に用意することになる。
- **ログイン前のデッキを、初めてログインした人へ引き継ぐ**：組んだものが無駄にならないが、「アカウントにデッキがまだ無い」の判定が取得中と区別しにくく、既存のデッキを上書きしかねない。
