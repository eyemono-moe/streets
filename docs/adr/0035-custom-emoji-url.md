# 作ったカスタム絵文字の URL は、指定そのものにして R2 から配る

「カスタム絵文字を作る」で作った画像は、次の URL に置く。リアクション（kind:7）の `emoji` タグや自分の絵文字（kind:10030）に書き込まれ、後から変えられない。

```
https://emoji.streets.eyemono.moe/v1/<書体>-<形>-<字の形>-<そろえ>-<文字色>-<縁取りの色|none>-<縁取りの太さ>/<文字>.png
```

- 文字は、行を改行でつないだ UTF-8 を base64url（詰め物なし）にしたもの
- 同じ見た目になる指定は 1 つの形にそろえてから名前にする（伸ばすときのそろえは `center`、縁取りが無いときの太さは `0`、色は小文字）。そろえた形でない名前は読まない
- `v1` の出力（描き方・フォント・輪郭）は変えない。変えるときは `v2` を足す
- 作るのは Worker（`POST /api/emoji`）で、R2 のバケット `streets-emoji` の同じ名前に置く。配るのはバケットに付けた `emoji.streets.eyemono.moe` で、Worker を通らない

組み立てと読み戻しは `packages/core/src/emoji-maker/url.ts`。

## なぜ

- **指定そのものにする**：同じ言葉を同じ見た目で作れば、誰が作っても同じ URL になり、リアクションの数が 1 つにまとまる。URL から指定を読み戻せるので「これを元に作る」ができ、R2 の中身が失われても描き直せる
- **R2 から直接配る**：画像はほかのクライアントからも表示されるたびに読まれる。Worker を通すと Workers Free の「1 日 10 万リクエスト」を表示で使い切りうる。R2 に独自のドメインを付ければ CDN のキャッシュが前に立ち、Worker は作るときだけ動く
- **文字を base64url にする**：文字には `/` `?` `#` `%` も入りうる。そのまま URL や R2 の名前にすると、エンコードのされ方でクライアントごとに別の名前になりうる

## 捨てた案

- **`streets.eyemono.moe/api/reaction/…` から Worker が返す**：開かれたときに描き直せるが、表示のたびに Worker のリクエスト数を使う
- **作った画像を、中身のハッシュの名前で置く**：名前は短いが、URL から指定を読み戻せず、R2 から消えたら戻せない
- **文字をそのまま（パーセントエンコードして）名前にする**：読みやすいが、上のエンコードの揺れがある
