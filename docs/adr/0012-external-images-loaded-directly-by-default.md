# 外部画像は既定で直接読み込み、プロキシ経由と非表示は設定で選べるようにする

他人の投稿に含まれる画像は、**既定では直接読み込む**。設定で「外部プロキシ経由」「画像を読み込まない」を選択できる。初回起動時にリスクを一度告知する。

## 受け入れたリスク

外部画像を直接読み込むと、**閲覧者の IP アドレスと User-Agent が画像ホストに渡る**。攻撃者は自分が管理するサーバの画像 URL を投稿するだけで、それをタイムラインに流した全員の IP を収集できる。**クリックを必要とせず、表示されるだけで発動する。**

それでも既定を直読みとしたのは、自前プロキシの帯域コストを作者個人が負担することになり、ユーザー数の増加とともに持続不能になるため。公開プロキシ（weserv.nl 等）を既定にする案は、画像ホストへの漏洩を**プロキシ運営者への閲覧履歴の漏洩に付け替えるだけ**であり、既定として押し付ける根拠がない。

これは [ADR-0001](./0001-others-first-self-via-settings.md)（他人が使えることを優先）が、コスト制約に対して譲った箇所である。

## Consequences

- **リスクの告知が必須。** 既定が安全側でない以上、ユーザーが知らないまま IP を晒す状態は許容できない。設定の存在を発見できる導線が必要。
- 将来ユーザー数が増え、かつ資金的な余裕ができた場合、既定をプロキシ経由に変更する余地を残す。本 ADR はそれを禁じない。
- アップロードする画像からは **EXIF を必ず除去する**（別要件）。これは本 ADR とは独立した、投稿者側のプライバシー保護。
