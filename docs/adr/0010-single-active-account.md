# 同時にアクティブなアカウントは常に1つとする

アカウントの切り替えは可能だが、**同時にアクティブなアカウントは常に1つ**。切り替えるとデッキごと入れ替わり、切り替え先アカウントの `kind:30078` からデッキを読み直す。**カラムごとに別アカウントを割り当てることはできない。**

## なぜ

「カラムごとにアカウントを指定できる」は TweetDeck 型 UI 本来の強みだが、v1 で3つの問題を同時に解く必要が生じる。

- **通知カラムの「自分宛」が誰宛か決まらない。**
- **署名時にどの鍵を使うかが決まらない。** カラムのアカウントか、アクティブなアカウントか。リアクション1つ押すたびに曖昧さが発生する。
- **デッキ設定（`kind:30078`）をどのアカウントに保存するかが決まらない。** [ADR-0013](./0013-deck-persisted-to-nip78.md) と直接衝突する。

単一アクティブとすることで、「署名対象」と「自分宛」が常に一意に定まる。

## Consequences

- 複数アカウントを同時に見張ることはできない。本アカウントのタイムラインとサブアカウントの通知を並べる、といった使い方は v1 では不可能。
- アカウント切り替え時にデッキを読み直すため、切り替えは瞬時ではない。読み込み中の状態表示が必要。
- 将来カラム単位のアカウント割り当てを入れる場合、上記3点を先に解く必要がある。段階的な拡張にはならない。
