## 直したこと

- 投稿の中のカスタム絵文字が読み込まれたとき、後ろの文字が横へ押し出されて動いていたのを直しました。読み込む前から絵文字の分の場所を空けておきます。
- Streets の人や投稿の URL を投稿に貼ったとき、リンクのカードに中身ではなく Streets の紹介が出ていたのを直しました。ほかのアプリやサービスに貼ったときも、より多くの場所で、その人の名前や投稿の本文がカードに出るようになりました。
- Streets のアドレスの後ろに `nostr:` 付きのリンクをそのまま続けた URL（`/nostr:npub1…` など）が「開けません」になっていたのを直しました。
