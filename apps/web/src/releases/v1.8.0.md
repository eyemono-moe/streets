## 新しくできること

- ログインしていなくても、Streets のデッキを開いて投稿を読めるようになりました。最初は紹介とログインのカラムと、いくつかの読めるカラムが並びます。いいねや返信などログインが要る操作を押すと、ログインの案内が出ます。
- ユーザーのカラムに「メディア」タブを追加しました。その人が画像や動画を添えた投稿を、タイル状に並べて見られます。
- 画像や動画を拡大表示したとき、元の投稿の書き手と本文の冒頭を下に出すようにしました。「投稿を開く」から、その投稿を開けます。
- 投稿の動画も、右上のボタンから拡大して見られるようになりました。
- Streets で開いた投稿や人のページの URL を X や Discord などに貼ると、本文やアイコンの入ったカードが出るようになりました。

## 変わったこと

- Streets の URL を貼ったときに出る題名と説明を、日本語にしました。
- スマートフォンなどで、ブラウザの上のバーの色が Streets の画面の色に合うようになりました。
- すでに開いているカラムと同じものを、上に重ねて開かないようにしました。
- リリースのお知らせを、Streets のアカウントから投稿するようにしました。
- Streets が使っているライブラリのライセンスを `/license.md` で公開しました。
