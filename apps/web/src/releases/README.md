# リリースノート

1 回のリリースにつき 1 ファイル。ファイル名はタグと同じ（`v1.2.3.md`）。ビルドのときに HTML にして「Streets について」の「リリースノート」に並べ、同じファイルから GitHub の Release も作る（`docs/release.md`）。

```md
---
date: 2026-10-01
---

## 新しくできること

- ……

## 直したこと

- ……
```

- 読むのは Streets を使う人。コードの言葉ではなく、画面で何が変わったかを書く
- 見出しは `##` から（版の番号と日付は画面が出す）
- 下書きは `.claude/skills/release-notes` の手順で作る
