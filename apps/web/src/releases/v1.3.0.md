## 新しくできること

- チャンネル（みんなで話せる公開のチャット）に参加できるようにしました。カラム追加の「チャンネル」から一覧を探して開き、発言や返信ができます。チャンネルを作ったり、自分のチャンネルの名前・説明・画像を直したりもできます。
- チャンネルで自分への返信やメンションがあると、通知に出るようにしました。チャンネルの中で、発言やユーザーをミュートすることもできます。
- ホームとユーザーのカラムに、フォローしている人（ユーザーのカラムではその人）のチャンネルでの発言も出るようにしました。カラムの設定の「表示するもの」で切り替えられます。
- 人をまとめた「リスト」を作れるようにしました。投稿のメニューやユーザー詳細から、人をリストに公開または非公開で足せます。
- リストの人の投稿を流すカラムを足せるようにしました。カラム追加の「リスト」から、自分のリストや、自分が入っているほかの人のリストを選べます。
- カラム追加から、ユーザーのカラムを足せるようにしました。名前を打つと、フォローしている人に加えて、検索するリレーからも人を探します。

## 変わったこと

- 本文の長い URL を縮めて表示するようにしました。押したときの飛び先は元の URL のままです。日本語を含む URL も、途中で切れずに 1 つのリンクになります。
- URL などから開いた、デッキに残していないカラムは、枠線ではなく上端の破線の帯で見分けるようにしました。
- 通知（トースト）が何枚も出たときに、重なって奥にあるのが分かるようにしました。狭い画面では、画面の上の中央に出します。
- 設定の「使うリレー」と「検索するリレー」で、リレーを足す欄にフォローしている人が使っているリレーなどの候補が出るようにしました。
- 高密度の表示・引用・返信先などでも、長い本文を途中で畳むようにしました。
- 絵文字ピッカーの検索欄に、打った文字を消す × を付けました。
