## 新しくできること

- チャンネル（みんなで話せる公開のチャット）が利用できるようにしました。カラム追加の「チャンネル」から開き、発言や返信ができます。チャンネルを自分で作ることもできます。
- ユーザーをまとめた「リスト」を作れるようにしました。投稿のメニューやユーザー詳細から、ユーザーをリストに公開または非公開で足せます。
- リストの人の投稿を流すカラムを足せるようにしました。カラム追加の「リスト」から、自分のリストや、自分が入っているほかの人のリストを選べます。
- カラム追加から、ユーザー詳細のカラムを足せるようにしました。

## 変わったこと

- 本文の長い URL を縮めて表示するようにしました。
- 設定画面などのリレーURL入力欄で、フォローしている人が使っているリレーなどの候補が出るようにしました。
- そのほか細かいUIの改善を行いました。
