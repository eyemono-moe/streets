## 変わったこと

- 大きな画像を添えたときは、送る前に 5MB 以内まで自動で縮めるようにしました。縮めている間も画面は止まりません。
- 既定の検索先を、止まっていたリレーから日本語やハッシュタグの検索に答えるリレーへ入れ替えました。
- 投稿や返信の欄を開いた時点で絵文字の一覧を読み始めるので、絵文字ピッカーを初めて開いたときに待たされにくくなりました。

## 直したこと

- 「未対応のイベントです」と出ていたプロフィールを、フォロー一覧と同じ人の行で表示するようにしました。押すとその人のカラムが開きます。
- 返信・引用のダイアログで絵文字ピッカーを開くと、検索欄に文字を打てなかったのを直しました。
