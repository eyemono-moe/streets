## 新しくできること

- 自分のステータス（いまの状態のひとこと）を設定できるようになりました。アカウントメニューの「ステータスを設定」か、自分のプロフィールから設定できます。
- ほかの人のステータスを、プロフィールに表示するようになりました。聴いている曲も名前の下に出ます。
- 投票を表示し、その場で投票できるようになりました。
- 長文の記事を表示できるようになりました。
- 画像や動画の投稿を表示するようになりました。
- ユーザーのカラムに「ピン留め」タブを追加し、その人がピン留めした投稿を見られるようになりました。
- 投稿にStreetsから送ったことを添える設定を追加しました。既定はオフです。
- 投稿の「︙」メニューから、その投稿を送ったアプリの説明を見たり、そのアプリで投稿を開いたりできるようになりました。

## 変わったこと

- 設定に「プライバシー」のページを追加し、「不具合と動作の速さの報告」を「表示」からここへ移しました。
