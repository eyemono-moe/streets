## 新しくできること

- 自分のステータス（いまの状態のひとこと）を設定できるようになりました。アカウントメニューの「ステータスを設定」か、自分のプロフィールから設定でき、リンクや消える時刻も付けられます。
- ほかの人のステータスを、プロフィールと、アイコンに触れたときに出る名刺に表示するようになりました。聴いている曲も名前の下に出ます。
- 投票を表示し、その場で投票できるようになりました。投票した後や締め切った後は、選択肢ごとの割合が出ます。
- 長文の記事をカードで表示し、押すとカラムで読めるようになりました。
- 画像や動画の投稿を表示するようになりました。
- ユーザーのカラムに「ピン留め」タブを追加し、その人がピン留めした投稿を見られるようになりました。
- 流れてきたリストをカードで表示し、押すとそのリストの人たちの投稿を流すカラムを開けるようになりました。
- 流れてきた絵文字セットをカードで表示し、そのまま自分の絵文字リストに加えられるようになりました。
- 記事やリストなどを指す引用・リンクから、指された先を開けるようになりました。これまでは「未対応の参照です」と出ていました。
- 投稿にどのアプリから送ったかを添える設定を追加しました（既定はオフ）。
- 投稿の「︙」メニューから、その投稿を送ったアプリの説明を見たり、そのアプリで投稿を開いたりできるようになりました。

## 変わったこと

- 設定に「プライバシー」のページを追加し、「不具合と動作の速さの報告」を「表示」からここへ移しました。
- リストの一覧の行に、メンバーの顔が並ぶようになりました。
- 設定の絵文字セットの行に、作った人と絵文字の数が出るようになりました。
